# 100th Day Donation Invitation

A premium, cinematic digital invitation website for a child's 100th Day Donation ceremony.

## Direction

- Mobile-first invitation experience
- Component-by-component cinematic opening
- Separate background, lotus, card, baby portrait, ribbon, seal, ornaments and petals
- Real HTML typography and interaction
- GSAP timeline controlling the complete opening sequence
- Smooth transition from the invitation card into the main website
- Next.js + TypeScript + Tailwind CSS + GSAP

## Opening sequence

1. Atmosphere fades in
2. Foreground lotus creates depth
3. Invitation card rises into view
4. Ribbon and seal loosen
5. Baby portrait reveals
6. Invitation typography appears in sequence
7. Open Invitation button becomes interactive
8. Card expands and transitions into the website

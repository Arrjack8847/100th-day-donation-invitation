# 100th Day Donation Invitation

A premium, cinematic digital invitation website for a child's 100th Day Donation ceremony.

## Direction

- Mobile-first invitation experience
- Short cinematic opening video
- Real HTML/CSS interaction layered over the video
- Smooth transition from opening into the website
- Next.js + TypeScript + Tailwind CSS + GSAP

## Opening media

Place the final opening videos here:

- `public/opening/intro-mobile.mp4`
- `public/opening/intro-desktop.mp4`

The opening video should end on a clean invitation composition so the real “Open Invitation” button can sit on top without feeling disconnected.
